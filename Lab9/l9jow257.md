# My Solution
```py
class Solution:
    def minCostClimbingStairs(self, cost: list[int]) -> int:
        '''
        dp, we just have to find the cheapest way to get to each square
        '''
        c1=cost[0]
        c2=cost[1]
        for i in range(2, len(cost)):
            temp=c2
            c2=min(c1+cost[i], c2+cost[i])
            c1=temp
        return min(c1,c2)
```
# The approach
In this problem, we're trying to find the cheapest way to get to the top of the staircase. However, this can be broken into subproblems, where we find the cheapest way to get to each stair, until we have gotten to the top. So, in my solution I find
the cheapest way to get to each next stair by keeping track of the cheapest way to get to the previous two stairs. Then, the cheapest way to get to the next stair is the cost of the next stair, plus the cheaper of the two previous stairs. In the end
we just return the cheaper of the top two stairs because we can summit the staircase from there.

# Runtime 
My solution to this problem takes `O(n)` time since we do one pass of the staircase, performing a constant amount of work per stair.
# Space
My solution to the problem takes `O(1)` space since I only create two variables, regardless of the size of the input.
