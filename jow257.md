# Time complexity
Since I use a hash map which has an insert of `O(n)` in the worst case, and I insert for each `n` person,  `O(n) * O(n) = O(n^2)`. However in practice, this would be closer to linear time, since the hash map will rarely end up being anywhere close
to `O(n)` time.
# Space complexity
I made a hash map that contains every person, so space complexity is `O(n)`.
