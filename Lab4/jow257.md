# My code
```
class Solution
  def maxProduct(self, nums: list[int])-> int:
    nums.sort()
    return (nums[-1]-1) * (nums[-2]-1)
```
# Why it works
The goal of the algorithm is to multiply the two largest integers and return the product. By sorting we guarantee that the two largest integers are the last and second to last indices. So we sort, then return the last two indices multiplied.
# Complexity analysis
## Runtime
The asymptotic runtime of the algorithm is `O(nlog(n))`, since sorting is `O(nlog(n))`. This has a small effect on the empirical runtime, since the input is constrained to be a length less than 500.
## Memory
The asymptotic space complexity of the algorithm is `O(1)`, since Python's .sort() method is in place.
